# Image-pipeline acceptance

The original 67 scenarios stay in place. Source pipeline checks add frozen-file behavior, all eight EXIF orientations, ICC/alpha, original metadata, 4001×3003 and 1×4000 inputs, cropped annotations, manual blur, cached backgrounds, encoded-byte limits and 64 MP rejection before native decoding. Full exports retain native source pixels beyond the 1400px preview boundary.

An `ImagePreview` is a display proxy, with independent original-to-proxy factors on x and y because each reduced dimension is rounded separately. Its backing image is internal to the core module. Preview source colors near a resampled edge may differ from a native-source reference within one proxy sample footprint, projected through the current crop and display scale. Flat interior ICC colors use a three-level per-channel tolerance. Annotation geometry, crop coordinates, output size and full-resolution export pixels are not relaxed. Tight crops requiring more source detail should use the retained original raster rather than magnify the whole-image proxy.

For the flat 4001×3003 crop fixture, cropped-native and whole-proxy drawing differ only in source-boundary antialias coverage: 2,750 perimeter pixels at the 800px output, maximum channel/alpha difference 37. That fixture permits at most 40 levels only within a one-device-pixel band around the projected source rectangle, limits changed pixels to its perimeter, and requires byte equality everywhere else. Redaction landmarks independently match original-pixel coordinates and native-source bounds. This tolerance does not apply to exported pixels or arbitrary source interiors.

The balance oracle is the accepted pre-v3 brute-force predicate with the original corner safeguard and two-pixel safety margin. The optimized boundary seeker must return exactly the same rectangle or nil for all 600 seeded fixtures and every position of a single pixel on opaque and transparent borders. The production path never downscales for balance and never creates the oracle's second owned byte array.
